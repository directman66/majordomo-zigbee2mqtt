# История изменений

## 1.0.0

- Плагин оформлен как полноценный пакет для «Маркета дополнений» MajorDoMo: добавлены `modinfo.json`, `module.xml`, `install.php`, скрипт сборки `build_package.ps1` и готовый архив `dist/zigbee2mqtt.tgz`.
- Добавлена документация по установке на русском языке: `docs/INSTALL.ru.md`.
- Исправлена ошибка в фильтре журнала: `is_array(explode('/', $path)[1])` всегда давал `false`, из-за чего исключения для устройств с `HISTORY = 0` не работали.
- Служебные топики `bridge/info/*` и `bridge/health` больше не сохраняются в таблицу `zigbee2mqtt_log`.
- Ограничен рост таблицы `zigbee2mqtt_log`: не более 1000 последних записей, после очистки выполняется `OPTIMIZE TABLE`.
- Значение `Z2M_HIST = 0` теперь означает полную очистку журнала.
- В `readme.md` добавлен раздел с описанием ограничения размера журнала и командами для одноразовой очистки.
