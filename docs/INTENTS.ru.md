# Голосовые команды и «Простые устройства»

Модуль умеет разбирать голосовые (и текстовые) команды на русском, английском и украинском языках и управлять устройствами Zigbee через MQTT. Интеграция с «Простыми устройствами» MajorDoMo выполняется через штатный модуль `devices`.

## Подключение разборщика

### Вариант 1 — сценарий (рекомендуется)

Импортируйте файл `scripts/zigbee2mqtt_intent.json` через **Сценарии → Импорт**. После этого доступен сценарий `zigbee2mqtt_intent`:

```php
$phrase = 'Включи лампу';
$res = runScript('zigbee2mqtt_intent');
// $res = array('ok', 'message', 'action', 'device', 'lang')
```

Сценарий также записывает ответ в переменную `zigbee2mqttLastResult`, удобную для голосового ответа.

### Вариант 2 — прямой вызов

```php
include_once(DIR_MODULES . 'zigbee2mqtt/zigbee2mqtt.intents.php');
$res = z2m_intent_handle('Выключи лампу');
```

### Вариант 3 — «Простое устройство»

Вызовите один раз:

```php
include_once(DIR_MODULES . 'zigbee2mqtt/zigbee2mqtt.intents.php');
$res = z2m_provision_simple_device();
```

Будут созданы:

- класс `SZ2MGateway`;
- объект `Z2MGateway` со свойствами `STATUS`, `status`, `LAST_INTENT`, `LAST_ERROR`, `DEVICE`;
- методы `intent`, `turnOn`, `turnOff`;
- запись в таблице `devices` с типом `relay`, заголовком «Шлюз Zigbee» и псевдонимами на трёх языках.

Тип `relay` выбран намеренно: ядро `devices` вызывает `turnOn`/`turnOff` именно для реле по командам «включи/выключи <устройство>». Повторный вызов обновляет существующую запись, а не создаёт копию.

Через объект команда вызывается так:

```php
callMethod('Z2MGateway.intent', array('phrase' => 'Покажи статус лампы'));
```

`turnOn` разрешает сопряжение (permit_join), `turnOff` — запрещает.

## Поддерживаемые команды

| Действие | Русский | English | Українська |
| --- | --- | --- | --- |
| Включить | включи лампу | turn on lamp | увімкни лампу |
| Выключить | выключи лампу | turn off lamp | вимкни лампу |
| Статус | статус лампы | status of lamp | стан лампи |
| Температура | какая температура датчик | temperature sensor | яка температура датчик |
| Разрешить сопряжение | разреши сопряжение | allow joining | дозволь спряження |
| Запретить сопряжение | запрети сопряжение | deny joining | заборон спряження |

Язык определяется по фразе, а не по настройкам интерфейса: можно говорить на любом из трёх языков независимо от выбранного языка MajorDoMo.

## Как находится устройство

Разборщик ищет имя среди полей `TITLE`, `DEVICE_NAME` и `IEEEADDR` таблицы `zigbee2mqtt_devices`. Допускается сокращение окончания: «лампу» совпадёт с «лампа», «датчике» — с «датчик». Если точного совпадения нет, используется поиск по части имени.

Для управления отправляется стандартная команда zigbee2mqtt:

```
<базовый_топик>/<friendly_name>/set  ->  {"state":"ON"}
```

Базовый топик берётся из настройки модуля `MQTT_QUERY` (по умолчанию `zigbee2mqtt`).

## Возвращаемое значение

| Ключ | Описание |
| --- | --- |
| `ok` | true, если команда выполнена |
| `message` | Ответ для голосового озвучивания |
| `action` | `on`, `off`, `status`, `temperature`, `join_on`, `join_off` или пусто |
| `device` | Найденное устройство |
| `lang` | `ru`, `uk` или `en` |

## Ограничения

- Команды temperatures и status читают метрики из объектов MajorDoMo. Если устройство не привязано к объекту с метрикой `temperature`, возвращается «Нет данных».
- Разборщик не изменяет настройки модуля и не перезапускает цикл.
- Для озвучивания ответа используйте `say($res['message'])` или `z2m_say()` из `zigbee2mqtt.i18n.php` (после принятия пул-реквеста с локализацией).
- Псевдонимы устройств задаются в `zigbee2mqtt_devices` и не затрагивают штатные имена объектов MajorDoMo.
