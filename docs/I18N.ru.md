# Языки интерфейса и голосовые фразы

Модуль поддерживает три языка: **английский (en)**, **русский (ru)** и **украинский (uk)**. Ядро MajorDoMo использует для украинского код `ua`, поэтому в пакете есть оба файла: `zigbee2mqtt_uk.php` и `zigbee2mqtt_ua.php`.

## Как выбрать язык

Язык берётся из системной настройки MajorDoMo `SETTINGS_SITE_LANGUAGE` (Настройки → Язык интерфейса). Дополнительные настройки модуля не нужны:

| Значение `SETTINGS_SITE_LANGUAGE` | Словарь модуля | Код голоса |
| --- | --- | --- |
| `en` | `zigbee2mqtt_en.php` | `en-US` |
| `ru` | `zigbee2mqtt_ru.php` | `ru-RU` |
| `ua` или `uk` | `zigbee2mqtt_uk.php` | `uk-UA` |

Если файл для текущего языка отсутствует, используется `zigbee2mqtt_default.php` (английский).

## Что именно переводится

1. **Текст интерфейса.** Страница настроек модуля использует константы `LANG_Z2M_*`. В шаблоне они выглядят как `<#LANG_Z2M_SETTINGS_MQTT#>`.
2. **Голосовые фразы.** Ключи `Z2M_VOICE_*` содержат готовые фразы для озвучивания состояний устройств и событий шлюза.
3. **Код языка синтеза речи.** Функция `z2m_lang_code()` возвращает `en-US`, `ru-RU` или `uk-UA` — этот код можно передать в TTS-генератор MajorDoMo.

## Использование в сценариях и правилах

Подключите библиотеку один раз:

```php
include_once(DIR_MODULES . 'zigbee2mqtt/zigbee2mqtt.i18n.php');
```

Получить код языка и строку:

```php
$code = z2m_lang_code();               // ru-RU / uk-UA / en-US
$text = z2m_tr('Z2M_VOICE_ON', array('Лампа'));
```

Озвучить фразу через стандартные `say()` / `sayTo()`:

```php
z2m_say('Z2M_VOICE_ADDED', array('Лампа'));          // на все терминалы
z2m_say('Z2M_VOICE_COMMAND_DONE', array(), 'tv');    // на терминал tv
z2m_say_device('ON', 'Лампа');                       // «Лампа включена»
```

`z2m_say_device()` сам разбирает значения `ON`, `OFF`, `1`, `0`, `TRUE`, `FALSE`, которые присылает zigbee2mqtt, и выбирает нужную фразу. Для числовых и строковых значений используется шаблон `Z2M_VOICE_STATE`.

## Список ключей

| Ключ | Назначение |
| --- | --- |
| `Z2M_LANG_NAME` | Название языка |
| `Z2M_SETTINGS_MQTT` | Заголовок раздела MQTT |
| `Z2M_LABEL_SUBSCRIPTION`, `Z2M_HINT_GATEWAYS` | Путь подписки и подсказка |
| `Z2M_LABEL_AUTH`, `Z2M_LOGIN`, `Z2M_PASSWORD` | Авторизация |
| `Z2M_SETTINGS_Z2M`, `Z2M_LABEL_FOLDER`, `Z2M_HINT_FOLDER`, `Z2M_LABEL_LOGLEVEL` | Настройки zigbee2mqtt |
| `Z2M_SETTINGS_SLS`, `Z2M_LABEL_SLS_IP`, `Z2M_HINT_SLS` | Шлюз SLS |
| `Z2M_SETTINGS_SYSTEM`, `Z2M_LABEL_HISTORY`, `Z2M_HINT_HISTORY` | Настройки MajorDoMo и журнал |
| `Z2M_LABEL_VIEW`, `Z2M_VIEW_TILES`, `Z2M_VIEW_TABLE`, `Z2M_LABEL_NTILES` | Режим отображения |
| `Z2M_LABEL_DEBUG` | Отладочные сообщения |
| `Z2M_VOICE_ON`, `Z2M_VOICE_OFF`, `Z2M_VOICE_STATE` | Состояние устройства |
| `Z2M_VOICE_ADDED`, `Z2M_VOICE_LOST` | Появление и потеря устройства |
| `Z2M_VOICE_BRIDGE_ONLINE`, `Z2M_VOICE_BRIDGE_OFFLINE` | Состояние шлюза |
| `Z2M_VOICE_UNKNOWN_COMMAND`, `Z2M_VOICE_COMMAND_DONE` | Результат голосовой команды |
| `Z2M_VOICE_LOG_CLEARED` | Очистка журнала |

## Добавление нового языка

1. Скопируйте `languages/zigbee2mqtt_default.php` в `languages/zigbee2mqtt_<код>.php`.
2. Переведите значения, оставив ключи без изменений.
3. Добавьте код в `z2m_language()` в `modules/zigbee2mqtt/zigbee2mqtt.i18n.php` при необходимости.

Ключи должны совпадать во всех словарях: ядро подставляет константы `LANG_Z2M_*` напрямую в шаблоны, а отсутствующий ключ приведёт к выводу имени константы вместо текста.
