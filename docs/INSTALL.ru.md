# Установка и обновление пакета Zigbee2MQTT

Версия пакета: **1.0.0**. Архив для Маркета дополнений: `dist/zigbee2mqtt.tgz`.

## Состав пакета

| Путь в архиве | Назначение |
| --- | --- |
| `modules/zigbee2mqtt/` | Код модуля, база устройств и страницы админки |
| `modules/zigbee2mqtt/ext/configuration.yaml` | Пример конфигурации zigbee2mqtt |
| `templates/zigbee2mqtt/` | Шаблоны интерфейса, карта сети, журнал |
| `scripts/cycle_zigbee2mqtt.php` | Цикл подписки на MQTT и обработки сообщений |
| `img/modules/zigbee2mqtt.png` | Иконка модуля |
| `modinfo.json`, `module.xml` | Метаданные для Маркета дополнений |
| `install.php` | Регистрация модуля при установке через Маркет |
| `readme.md`, `CHANGELOG.md`, `docs/` | Документация на русском языке |

Архив собирается скриптом `build_package.ps1` из корня репозитория. Все пути внутри архива относительные от корня MajorDoMo, родительской папки нет.

## Установка через Маркет дополнений

1. В панели MajorDoMo откройте **Маркет дополнений → Загрузить дополнение**.
2. Выберите `dist/zigbee2mqtt.tgz` и подтвердите установку.
3. MARKET распакует архив в корень MajorDoMo, выполнит `install.php` (модуль зарегистрируется автоматически), затем скопирует остальные файлы.
4. Обновите страницу **Модули** — в разделе устройств появится `zigbee2mqtt`.

## Ручная установка

1. Распакуйте `dist/zigbee2mqtt.tgz` в корень MajorDoMo (там, где находятся `config.php`, `modules`, `templates`).
2. Убедитесь, что файлы встали на свои места:

```bash
ls modules/zigbee2mqtt/zigbee2mqtt.class.php
ls templates/zigbee2mqtt/devices.html
ls scripts/cycle_zigbee2mqtt.php
```

3. Откройте любую страницу панели — конструктор модуля вызовет `checkInstalled()` и создаст таблицы базы данных.
4. Перезапустите цикл `cycle_zigbee2mqtt` (через **Циклы** либо установкой `cycle_zigbee2mqttControl = restart`).

## Зависимости

- В ядре MajorDoMo должна быть библиотека `3rdparty/phpmqtt/phpMQTT.php` — она входит в стандартную поставку.
- Модуль `control_modules` используется для управления циклами.
- Брокер MQTT (например, Mosquitto), доступный с хоста MajorDoMo.
- Сама служба zigbee2mqtt с включённым MQTT-интерфейсом. В репозитории есть пример `modules/zigbee2mqtt/ext/configuration.yaml`.

## Проверка после установки

1. **Модуль.** В списке модулей есть `zigbee2mqtt`, страница открывается без ошибок PHP.
2. **Таблицы.** В SQL-терминале выполняются запросы к `zigbee2mqtt_devices`, `zigbee2mqtt_log`, `zigbee2mqtt_grouplist`, `zigbee2mqtt_bind`.
3. **Цикл.** В **Циклах** виден `cycle_zigbee2mqtt` со свежим временем последнего запуска.
4. **Подписка.** В настройках указаны правильные `MQTT_HOST`, `MQTT_PORT`, `MQTT_QUERY` (по умолчанию тема `zigbee2mqtt/#`). После включения сопряжения устройства появляются на странице модуля.
5. **Журнал.** Таблица `zigbee2mqtt_log` не растёт бесконечно: после EVENT `HOURLY` остаётся не более 1000 последних записей, а файл `.MYD` пересоздаётся командой `OPTIMIZE TABLE`.

## Обновление

1. Сделайте резервную копию базы данных и каталога `modules/zigbee2mqtt`.
2. Установите новый архив поверх прежней версии тем же способом.
3. Проверьте, что настройки MQTT сохранились: они лежат в конфигурации модуля и при обновлении файлов не перезаписываются.
4. Если на диске уже накоплен большой файл `zigbee2mqtt_log.MYD`, дождитесь EVENT `HOURLY` или выполните очистку вручную — команды приведены в `readme.md`.

## Откат

1. Верните файлы предыдущей версии из резервной копии.
2. Удалите модуль через **Модули → Удалить**, если нужно вернуть прежнее состояние реестра. Таблицы базы данных при удалении модуля не удаляются; при необходимости их чистят вручную.
3. Перезапустите цикл `cycle_zigbee2mqtt`.

## Известные особенности

- Модуль по-прежнему использует движок `MyISAM` для таблицы журнала. Это сделано исторически; в пакете добавлен `OPTIMIZE TABLE`, который компенсирует особенность движка.
- При установке только папки `modules/` без папки `languages` интерфейс работает на языке по умолчанию. Полный комплект словарей появится в следующем релизе.
- Для работы карты сети в шаблонах используется локальная библиотека `vis.js` из `templates/zigbee2mqtt/vis-4.21.0/dist`. В архив включены только необходимые файлы.
